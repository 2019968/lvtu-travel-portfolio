# 调研结果摘要

**数据范围**：150 份实际回收的大学生短途出行问卷；便利抽样，广东样本 75/150（50.0%），其中佛山 60/150（40.0%）。10 份作答时长低于 90 秒，未剔除；跳题、重复提交和多选超选检查未发现异常。

## 主要发现

| 问题 | 结果 | 解释 |
|---|---:|---|
| 过去半年自报曾因规划麻烦放弃出行 | 99/150（66.0%） | 自报经历，不是产品流失率 |
| 将“攻略质量差、广告或过度美化”列为规划困扰 | 77/150（51.3%） | 多选题，可与其他困扰同时选择 |
| 将“信息分散、需要切换 App”列为困扰 | 71/150（47.3%） | 多选题 |
| 选择美食红黑榜功能 | 72/150（48.0%） | 功能选择率第一 |
| 选择学生行程模板功能 | 68/150（45.3%） | 功能选择率第二 |
| 选择按预算推荐功能 | 66/150（44.0%） | 当前原型仅提供预设模板的预算分档筛选 |

在回答“最近一次出行”相关题目的 143 人中，79 人（55.2%）在规划时打开过至少 3 个 App；72 人（50.3%）做攻略超过 1 小时。另有 7 人过去半年出行 0 次，按问卷跳题逻辑未回答这些题。

## 结论边界

本问卷只能描述本样本的自报情况，不能代表全国大学生，更不能推算上线后的使用、留存或付费。功能选择率表示受访者在问卷中勾选过对应选项；尚未做真实产品使用测试。困扰与功能的共现分析只描述同时出现，不证明因果。项目没有访谈，因此无法解释每位受访者为何作出选择。
